# GAANSAOBA - Plateforme Hôtelière du Burkina Faso

**Version 2.0 - Déploiement Production**

## Démarrage rapide

```bash
pip install -r requirements.txt
python app.py
```

## Technologies

- **Backend** : Flask + SQLAlchemy 1.4 + Gunicorn
- **Frontend** : HTML + Tailwind CSS + Jinja2
- **Paiement** : Simulation Mobile Money (Orange, Moov, Telecel)
- **PWA** : Installable sur Android et iPhone

## Fonctionnalités

- ✅ Menu mobile responsive (hamburger)
- ✅ Traduction FR/EN
- ✅ Réservation en ligne avec QR Code
- ✅ Dashboard Admin, Hôtelier, Client
- ✅ PWA installable sur téléphone
- ✅ Paiement Mobile Money simulé
